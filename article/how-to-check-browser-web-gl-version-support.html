How to Check Browser WebGL Version Support

WebGL enables high-performance 2D and 3D interactive graphics within any compatible web browser without requiring third-party plugins. This article provides a quick guide to determining the exact WebGL version (such as WebGL 1.0 or WebGL 2.0) supported by your current browser, covering methods via developer console commands, built-in browser status pages, and diagnostic websites.

Method 1: Using the Developer Console (JavaScript)

The most direct way to check WebGL version support programmatically is through the browser's developer tools.

  1. Open your browser's Developer Tools by pressing F12 (or Ctrl + Shift + I on Windows/Linux, Cmd + Option + I on macOS).
  2. Click on the Console tab.
  3. Paste and run the following snippet:
const canvas = document.createElement('canvas');
const gl2 = canvas.getContext('webgl2');
const gl = canvas.getContext('webgl') || canvas.getContext('experimental-webgl');

if (gl2) {
  console.log("Supported: " + gl2.getParameter(gl2.VERSION));
  console.log("Shading Language: " + gl2.getParameter(gl2.SHADING_LANGUAGE_VERSION));
} else if (gl) {
  console.log("Supported: " + gl.getParameter(gl.VERSION));
  console.log("Shading Language: " + gl.getParameter(gl.SHADING_LANGUAGE_VERSION));
} else {
  console.log("WebGL is not supported on this browser.");
}

If the browser supports WebGL 2, the output will start with WebGL 2.0. If it only supports the older standard, it will output WebGL 1.0.

Method 2: Inspecting Internal Browser Diagnostics

Most modern browsers offer internal configuration pages that detail hardware acceleration and graphic API support.

  • Google Chrome, Microsoft Edge, Brave, and Opera: Type chrome://gpu (or edge://gpu in Edge) into your address bar and press Enter. Look for the Graphics Feature Status section. Check the entries for WebGL and WebGL2 to see if they are labeled "Hardware accelerated."
  • Mozilla Firefox: Type about:support into the address bar and press Enter. Scroll down to the Graphics section to review details under WebGL 1 Driver Version and WebGL 2 Driver Version.
  • Apple Safari: Ensure the "Develop" menu is enabled under Safari Settings > Advanced. WebGL 2 is enabled by default in modern Safari releases, but you can inspect feature toggles under Develop > Feature Flags.

Method 3: Using WebGL Test Websites

If you prefer a graphical interface without using code:

  1. Navigate to diagnostic websites such as webglreport.com or get.webgl.org.
  2. These tools automatically detect the active context and display tabs for WebGL 1 and WebGL 2, detailing driver version numbers, supported extensions, maximum texture sizes, and the GPU hardware currently handling rendering tasks.
