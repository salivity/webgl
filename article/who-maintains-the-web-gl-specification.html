Who Maintains the WebGL Specification?

WebGL allows modern web browsers to render complex 2D and 3D graphics directly on your screen using hardware acceleration without third-party plugins. This article identifies the organization responsible for maintaining and advancing the WebGL specification, details how the governing process works, and outlines the relationship between the standard and the broader web graphics ecosystem.

The organization that actively maintains and updates the WebGL specification is The Khronos Group.

Founded in 2000, The Khronos Group is an open, non-profit, member-driven consortium of over 150 leading hardware and software companies, including Apple, Google, Mozilla, Microsoft, NVIDIA, Intel, and AMD. Within this consortium, the WebGL Working Group directly manages the standard. This specialized working group includes representatives from major browser vendors and GPU manufacturers who collaborate to design, review, and ratify each iteration of the WebGL specification.

The WebGL Working Group focuses on several key responsibilities:

  • Drafting Specifications: Khronos defines the application programming interfaces (APIs) that expose GPU functionality securely to JavaScript. WebGL 1.0 is derived from OpenGL ES 2.0, while WebGL 2.0 is based on OpenGL ES 3.0.
  • Conformance Testing: To ensure that WebGL renders consistently across different operating systems, browsers, and graphics hardware, Khronos develops and maintains an extensive Conformance Test Suite (CTS). Browsers must pass these tests to officially claim WebGL conformance.
  • Security and Stability: Because WebGL gives web applications low-level access to the graphics card, the working group continuously refines the specification to patch security vulnerabilities, prevent denial-of-service exploits, and protect user data from memory leaks.
  • Extension Management: Khronos standardizes both vendor-specific and cross-vendor extensions, enabling developers to access advanced GPU capabilities before they become part of the core specification.

While the modern web graphics landscape is gradually expanding toward newer APIs like WebGPU (developed under the W3C with Khronos collaboration), The Khronos Group remains the official steward of WebGL, ensuring continuous bug fixes, security updates, and backward compatibility across the web.
